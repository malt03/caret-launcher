# 実機での動作確認リスト（2026-11-24 からのまとめての修正）

まとめて自律的に進めた修正の記録と、実機（Pixel）での確認手順。各項目は「操作 → 期待結果」。確認が済んだら `[x]` にする。

## ホームのドラッグと読み込み

- Tex-4z1w ドラッグ元の情報（mDragInfo）が残る / Tex-ijxl 同じアイテムが2つ残る（3ccc1d5, 3221066）
  - [ ] ホームのアプリを長押ししてメニューだけ出して離し、続けて検索結果のアプリをホームの空きセルにドラッグして落とす → 落とした位置に1つだけ置かれ、最初のアプリは元の位置のまま
  - [ ] ホームのアプリを「アンインストール」に落とし、ダイアログでキャンセル → アプリがホームの元の位置に戻る。そのあと「＋」でショートカットを追加しても、そのセルに重ならない
  - [ ] 上と同じくダイアログを出したままホームボタンで戻る → アプリが元の位置に戻り、続けて別のアイテムをドラッグして落としても二重にならない
  - [ ] ホームのアプリを「アンインストール」に落としてアンインストールする → ホームからそのアプリが消える
  - [ ] アイテムをドラッグ中に、通知からアプリを開くなどでほかの画面を前に出し、戻る → ドラッグは取り消され、アイテムは元の位置にあり、編集モードは終わっている（新しい挙動。Launcher.onPause と同じ）
- Tex-9x44 作り直した Activity で古い読み込みが走る（3cfd853）
  - [ ] ダークモードの切り替え、言語の変更、文字色が変わる壁紙への変更をする → ホームの配置がそのまま出て、アイテムが消えたり重複したりしない
  - [ ] 表示サイズを変えてグリッドが変わる → これまでどおりアイテムが新しいグリッドに移る
- Tex-ukrg フォルダの長押しメニュー（8d42d20）
  - [ ] ホームのフォルダを長押しして指を離す → フォルダの横にメニュー（「削除」）が出る
  - [ ] フォルダを長押ししたまま指を動かす → メニューが閉じてフォルダのドラッグに移り、別のセルに落とせる
  - [ ] メニューの「削除」を押す → フォルダが中身ごとホームから消え、再起動しても戻らない
  - [ ] メニューが出ている状態でメニューの外をタップ → メニューが閉じる。フォルダをタップするとフォルダが開く
  - [ ] ウィジェットを長押し → これまでどおりメニュー（「削除」、設定し直せるものは「設定」も）とリサイズ枠が出て、動かすとドラッグに移る

## 全アプリ一覧と検索

- Tex-solu ライトモードで文字とハンドルが透明になる（63bb298）
  - [ ] ライトモードで中間色・単色の壁紙にする → 検索結果のアプリ名、全アプリ一覧のハンドル、ステータスバー・ナビゲーションバーのアイコンが見える
- Tex-ny2k 全アプリ一覧のスワイプの不具合3件（e80b197）
  - [ ] 検索フィールドに文字を入れ、フィールドの上で指を少し上下にぶらして離す → 入力した語が残り、キーボードも出たまま
  - [ ] 一覧を開いて一覧の中で検索し、下に少し引いて閾値の手前で離す。また閾値を越えてから上に戻して離す → どちらも検索語が残り、キーボードの状態も変わらない
  - [ ] 上スワイプで開く途中（離した直後のアニメーション中）にシートをタップする → シートが途中で止まらず、開くか閉じるかのどちらかまで動き切る
  - [ ] 下スワイプで閉じるアニメーション中に指で掴んで上へ動かす → シートが指に付いてくる。離すと開くか閉じるかで止まり、半端な位置に残らない
  - [ ] 戻る操作で一覧を閉じるアニメーション中に一度タップする → アニメーションは止まらず閉じ切り、フィールドにフォーカスとキーボードが戻る（Launcher3 と同じく、ジェスチャーでないアニメーションはタップで止まらない）
  - [ ] 一覧の中で検索し、結果を下へスクロールしてから結果の上で下にスワイプする → 一覧は閉じず、結果が上へスクロールする。結果を一番上まで戻してから下にスワイプする → 閉じる
- Tex-ypdf 全アプリ一覧のメニューから追加しても一覧が閉じない（aa8c04e）
  - [ ] 全アプリ一覧でアプリを長押しし、ショートカットの「＋」を押す → 一覧がアニメーションで閉じ、そのあとホームの空きセルにショートカットが出て弾む
  - [ ] 検索結果から同じ「＋」を押す → 入力が消えてホームに置かれ、弾む（今までどおり）
- Tex-fco2 全アプリ一覧のハプティックと補間（e27bb71）
  - [ ] ホームの空き領域を長押しして「アプリのリスト」 → 開き始めに軽いタップのハプティックが鳴る
  - [ ] 上スワイプで開く、下スワイプで閉じる → どちらも閾値を越えたところでハプティックが鳴る（今までどおり）
  - [ ] メニューから開く、戻るで閉じる → フィールドの動きは今までどおり。ホームの縮小とぼかしは等速寄りになる（開くときは前よりゆっくり強まる）
- Tex-2t22 検索の並び順（183119e）
  - [ ] 英字・記号で始まる名前のアプリと普通の英字名のアプリの両方に一致する語で検索する → 英字・数字で始まる名前が先に並び、全アプリ一覧と同じ順になる
  - [ ] 日本語の名前のアプリが複数一致する語で検索する → 並び順に違和感がないか（Launcher3 の LabelComparator にそろえたため、端末の言語が日本語でないときはかな・漢字の並びが前と変わる。気になるなら 183119e を戻して日本語の照合順に固定する）
