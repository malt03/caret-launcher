- 長押しとメニューを、アプリ側の `ItemLongClickListener.kt` から上流の derived コピー（`ItemLongClickListener`、`PopupControllerForAppIcon`、`PopupControllerForExtraHomeScreenItems`、`PopupDataSource`、`LauncherPopupItemDragHandler`）に変えた。メニューの項目（検索文字列を編集・アプリ情報）だけアプリが決める。エミュレータ（Small_Phone）で、ホームのアプリとフォルダの長押しメニュー、全アプリ一覧のアプリの長押しメニュー（ショートカット付き）とホームへのドラッグを確かめた
  - [ ] ホームのアプリ・フォルダの中のアプリ・全アプリ一覧と検索結果のアプリを長押し → 前と同じメニュー（アプリのショートカット、検索文字列を編集、アプリ情報）が出る
  - [ ] メニューのアプリのショートカットを長押ししてホームへドラッグ → 置ける
  - [ ] フォルダを長押し → 「削除」だけのメニュー。「削除」→ フォルダと中身が消える
  - [ ] ウィジェットを長押し → 「削除」（設定できるウィジェットは「設定」も）とリサイズ枠が出る。「設定」→ ウィジェットの設定画面が開き、戻ると反映される

## グリッドの決め方を Launcher3 の InvariantDeviceProfile に（Tex-heiy）

エミュレータ（Small_Phone、Pixel9ProFold）で、前の計算と全部の値が同じことを並べて確かめた（閉じた状態、開いた状態で 0・90・270 度から起動）。

- [ ] 実機でホームを開く → 列数・行数・アイコンの大きさ・全アプリ一覧のセルの高さが前と同じ
- [ ] 横向きのまま端末を再起動し、横向きでホームを開く → 縦向きで開いたときとグリッドが同じ（大画面の端末のみ）

## ホームのモデルを Launcher3 の LauncherModel・LoaderTask に（Tex-mci4・Tex-ttho・Tex-eg3z）

モデルを上流と同じく裏のスレッドに移した。エミュレータ（Small_Phone）で、読み込み・全アプリ一覧からの追加・移動・フォルダの作成と再起動後の読み込み・「削除」・アプリの一時停止と再開（アイコンがグレーになって戻る）・DB の移行テスト（androidTest）を確かめた。

- [ ] 更新してから最初にホームを開く → 前の配置（アプリ・ショートカット・フォルダ・ウィジェット）がそのまま出る。消えたものはない（念のため、最初の1回だけ `favorites` を `favorites_backup_textlauncher` に写している）
- [ ] アプリをアンインストールする → ホームとフォルダからそのアプリが消える。全アプリ一覧からも消える
- [ ] アプリを入れる → 全アプリ一覧と検索に出る
- [ ] アプリのショートカット（長押しメニューからドラッグして置いたもの）を、そのアプリ側で無効にする → ホームから消える。名前を変えたものは名前が変わる
- [ ] アイコンのテーマ（テーマアイコン）を切り替える → ホームと全アプリ一覧のアイコンが作り直される
- [ ] 画面の大きさが変わる操作（折りたたみの開閉など）でグリッドが変わる → アイテムが新しいグリッドに移し替えられる
- [ ] ウィジェットを置いて再起動する → ウィジェットが残る。提供元のアプリを消すとウィジェットも消える

## ウィジェットとショートカットの追加の流れを互換の Launcher に（Tex-q3gh の後半）

エミュレータでは、ピッカーの「追加」から OS の許可ダイアログが出るところまで確かめた（ダイアログはエージェントが操作しないので、その先は未確認）。

- [ ] ピッカーで設定画面のないウィジェットを「追加」し、許可ダイアログで「作成」→ ホームの空いたセルにウィジェットが置かれ、リサイズ枠が出る
- [ ] 許可ダイアログで「キャンセル」→ 何も置かれない。もう一度追加しても前の分が残っていない
- [ ] 設定画面のあるウィジェットを追加し、設定画面で完了 → 設定の後にウィジェットが置かれる。設定画面で戻る → 何も置かれない
- [ ] ピッカーからウィジェットをドラッグして空きセルに落とす → そのセルに置かれる
- [ ] ピッカーのショートカット（作成画面のあるもの）を追加し、作成画面で完了 → ホームに置かれる。アイテムの上に落としたときはフォルダになる
- [ ] 設定画面を開いたままホーム画面を回転するなどで Activity が作り直される → 戻ってから置かれる
- [ ] ホームのウィジェットを長押しし、メニューの「設定」→ ウィジェットの設定画面が開く

## ほかのアプリからのピン留めの要求（Tex-iuyb）

ビルドとユニットテストまで。エミュレータは許可ダイアログが開いたままだったので、画面では確かめていない。

- [ ] Chrome で任意のページを開き、メニューの「ホーム画面に追加」→「インストール」または「追加」→ ホームアプリの確認のシートが出る
- [ ] シートの「追加」→ シートが閉じ、ホームに戻るとショートカットが空いたセルに置かれる（少し跳ねて出る）
- [ ] シートからショートカットをドラッグしてホームの好きなセルに落とす → そこに置かれる
- [ ] ホームがいっぱいのときに「追加」→ 置かれない（落ちない）
- [ ] ウィジェットをピン留めするアプリ（例: 時計や天気のアプリの「ホームに追加」）から → シートが出て、「追加」で OS の許可ダイアログのあとホームに置かれる
- [ ] ピン留めしたショートカットのアプリをアンインストールする前に、まだ置かれていない（キューにある）とき → キューからも消え、あとで置かれない
