# Pixel 6a での実機確認（ウィジェット、グリッド、速さ）

エミュレータだけで確認した変更を、Pixel 6a（Android 17）で確かめる。
- グリッド（9cb531f）：Launcher3 と同じ選び方で 5列・アイコン約56dp（147px）になり、4列で置いていたアイテムが5列に移し替えられること
- ウィジェットの長押し：メニュー（削除・設定）とリサイズ枠が出て、キーボードが下りること。つまみのタップで＋／−、つまみのドラッグでリサイズ、枠の外のタップで閉じてキーボードが戻ること。指を動かすとドラッグに移り、落としたあとに枠が出ること
- メニューの「削除」（エミュレータでは未確認）と「設定」
- 速さ：エミュレータ（ホストの負荷が高い状態）では、最初に枠を出したときにデバッグビルドで ANR、リリースビルドでも 282 フレームのコマ落ちがあった。実機のリリースビルドで、最初の表示がもたつかないか見る。もたつくなら Compose の初回の構成を前もって済ませる（Launcher3 はベースラインプロファイルを持つ）などを考える
