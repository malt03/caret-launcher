# アプリとフォルダの表示

ホームにアプリとフォルダを表示する。
- アプリは1セル、タップで起動（学習は記録しない）
- フォルダは名前なし。アイコンは中のアプリのプレビュー（Launcher3 と同様）
- タップでフォルダを開く。中のアプリもアプリ名なし
仕様: docs/spec.md 5.2

## Acceptance Criteria

- [ ] ホームのアプリをタップすると起動する
- [ ] フォルダのアイコンに中のアプリのプレビューが出る
- [ ] フォルダをタップすると中身が開き、そこから起動できる
