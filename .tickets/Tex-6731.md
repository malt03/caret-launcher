# バックアップの対象を決める

allowBackup は有効だが、backup_rules.xml と data_extraction_rules.xml が雛形のまま（中身はコメントだけ）なので、アプリのデータが全部バックアップされる。アイコンのキャッシュ（app_icons.db。数 MB）まで含まれる。
- 残すもの：launcher.db（ホームの配置、検索文字列、学習）、shared_prefs（アイコンの設定、共有ボタン、グリッドの記録）
- 外すもの：app_icons.db（作り直せるキャッシュ）
- 別の端末に復元したとき、入っていないアプリやウィジェット（ウィジェットの id は端末ごと）がどうなるかを確かめる。Launcher3 は独自の BackupAgent と favorites の restored の列で扱っている
- クラウドのバックアップと端末間の移行（device-transfer）の両方を書く
